# pipes-mission
    A mobile game that raises awareness about clean water conservation.

## Pipe puzzle

The game contains three generated pipe-repair levels:

- Level 1 uses a 3x3 board.
- Level 2 uses a 4x4 board.
- Level 3 uses a 5x5 board.

Each level creates a valid faucet-to-bucket solution first, then scrambles the
pipe rotations. Click or tap a pipe to rotate it clockwise. Water only travels
between physically adjacent pipes whose connection directions match. Reaching
the bucket completes the level, awards a time-based bonus, and advances to the
next board.
